Entenda o que acontece por trás de um site ou aplicativo: bancos de dados, regras de negócio e comunicação entre sistemas.

Sobre o curso

Aqui você vai sair do front-end e aprender como o servidor processa informações, armazena dados e responde às requisições dos usuários, usando PHP e um banco de dados de verdade.

O que você vai aprender

✓Fundamentos de PHP
✓Manipulação de formulários com $_POST e $_GET
✓Conexão com banco de dados MySQL
✓Criação de uma API simples
✓Autenticação e login de usuários
✓Boas práticas de organização de backend
