Sobre o curso

Este curso foi pensado para quem nunca programou e quer dar os primeiros passos no desenvolvimento web. Você vai entender como um site é estruturado, estilizado e ganha interatividade, construindo projetos reais desde a primeira aula.

O que você vai aprender

✓Estrutura de páginas com HTML5
✓Estilização com CSS3, Flexbox e Grid
✓Lógica de programação com JavaScript
✓Layouts responsivos (mobile-first)
✓Boas práticas de organização de código
✓Publicação de um site na prática

Pré-requisitos

Nenhum conhecimento prévio é necessário. Só é preciso ter vontade de aprender e um computador com acesso à internet.
